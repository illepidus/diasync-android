# Установка Diasync

Diasync состоит из трёх APK:

* `diasync-app-release-X.Y.apk` — приложение для телефона;
* `diasync-wear-release-X.Y.apk` — приложение и источник данных для часов;
* `diasync-watchface-release-X.Y.apk` — циферблат.

`X.Y` — номер версии. Все три APK должны быть из одного релиза. Телефонное и часовое приложения
также должны быть подписаны одним ключом, поэтому не смешивай release APK с прежними debug-сборками.

## Что потребуется

* Android-телефон и часы Galaxy Watch с Wear OS, уже связанные друг с другом через Galaxy Wearable;
* компьютер с Windows, macOS или Linux;
* Wi-Fi, к которому можно одновременно подключить компьютер и часы;
* актуальный `adb` из [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools);
* три APK со страницы [Releases](https://github.com/illepidus/diasync-android/releases).

Перед установкой обнови систему часов до актуальной доступной версии. Старые версии Wear OS могут
не поддерживаться.

## 1. Скачивание APK

1. Открой на телефоне страницу GitHub Releases и выбери нужный релиз.
2. В разделе **Assets** скачай `diasync-app-release-X.Y.apk`.
3. На компьютере открой тот же релиз и скачай:
   * `diasync-wear-release-X.Y.apk`;
   * `diasync-watchface-release-X.Y.apk`.
4. Проверь, что `X.Y` во всех трёх именах совпадает.

Не скачивай файлы `Source code`: для установки они не нужны.

## 2. Установка приложения на телефон

1. На телефоне открой скачанный `diasync-app-release-X.Y.apk`. Обычно файл находится в приложении
   **Загрузки**, **Мои файлы** или в списке загрузок браузера.
2. Если Android заблокировал установку, нажми **Настройки** в сообщении и разреши приложению,
   из которого открыт APK, **Установку неизвестных приложений** или **Установку из этого источника**.
3. Вернись к APK и нажми **Установить**.
4. После установки можно вернуть запрет на установку из этого источника.
5. Открой приложение **Diasync**.

Если Android сообщает, что приложение не установлено, а на телефоне уже была debug-сборка Diasync,
см. раздел [Конфликт подписи](#конфликт-подписи).

### Первичная настройка телефона

1. На главном экране Diasync открой раздел **Connection**.
2. Проверь **Backend HTTPS URL**. Если используется стандартный сервер, оставь уже указанное
   значение.
3. Введи свой **User ID / token**.
4. Нажми **Start monitoring**.
5. Разреши уведомления. Без этого разрешения непрерывный мониторинг не запустится.
6. Вернись на главный экран. Дождись состояния **Connected** и появления последнего значения.

Первое получение данных может занять некоторое время. Не продолжай диагностику часов, пока телефон
сам не показывает актуальное значение. `User ID / token` является секретом: не публикуй его и не
вставляй в команды или скриншоты.

## 3. Подготовка `adb` на компьютере

1. Скачай SDK Platform-Tools для своей операционной системы и распакуй архив.
2. Открой терминал в папке `platform-tools` либо добавь эту папку в `PATH`.
3. Проверь запуск:

   ```text
   adb version
   ```

Если команда не найдена, запускай `adb` полным путём. На macOS и Linux из текущей папки это обычно
`./adb`, на Windows — `adb.exe`.

## 4. Подключение часов к компьютеру

Названия пунктов могут немного отличаться между версиями One UI Watch.
[Официальная инструкция Samsung](https://developer.samsung.com/health/sensor/guide/connect-watch.html)
содержит снимки экранов для актуального варианта меню.

### Включение режима разработчика

1. На часах открой **Настройки → Об устройстве / Сведения о часах → Сведения о ПО**.
2. Нажми на **Версия ПО** пять раз, пока не появится сообщение о включении режима разработчика.
3. Вернись в основные настройки и открой новый раздел **Параметры разработчика**.
4. Включи **Отладка ADB**.
5. Включи **Беспроводная отладка / Wireless debugging** и подтверди разрешение для текущей сети.
6. Если есть пункт **Отключить автоматический Wi-Fi / Turn off automatic Wi-Fi**, включи его на
   время установки. Это не даст часам разорвать Wi-Fi-соединение во время работы `adb`.
7. Убедись, что часы и компьютер подключены к одной Wi-Fi-сети.

### Сопряжение через код

1. На часах открой **Параметры разработчика → Беспроводная отладка → Сопряжение устройства с
   помощью кода / Pair new device**.
2. Часы покажут IP-адрес, порт сопряжения и шестизначный код. Не закрывай этот экран.
3. На компьютере выполни, подставив адрес и **порт сопряжения** с часов:

   ```text
   adb pair 192.168.1.50:37123
   ```

4. Введи показанный часами код. В терминале должно появиться сообщение об успешном сопряжении.
5. Вернись на часах на основной экран **Беспроводная отладка**. Там указан IP-адрес с другим,
   **портом подключения**. Выполни:

   ```text
   adb connect 192.168.1.50:42517
   ```

   Порт из `adb pair` и порт из `adb connect` обычно различаются. Используй именно тот порт, который
   показан на соответствующем экране часов.

6. Если часы запросят разрешение на отладку, выбери **Всегда разрешать с этого компьютера** и
   подтверди.
7. Проверь подключение:

   ```text
   adb devices
   ```

   В списке должна быть строка наподобие:

   ```text
   192.168.1.50:42517    device
   ```

Адрес `192.168.1.50:42517` в следующих командах называется `SERIAL`. Каждый раз подставляй вместо
`SERIAL` фактический адрес из `adb devices`.

### Старое меню «Отладка по Wi-Fi»

Если на часах нет сопряжения по коду, но есть **Debug over Wi-Fi**, включи его, запиши показанный
адрес, обычно с портом `5555`, и выполни:

```text
adb connect 192.168.1.50:5555
adb devices
```

Подтверди разрешение на экране часов.

## 5. Установка приложения и циферблата на часы

Открой терминал в папке, куда скачаны два APK, либо укажи полный путь к каждому файлу.

1. Установи часовое приложение:

   ```text
   adb -s SERIAL install -r "diasync-wear-release-X.Y.apk"
   ```

2. Дождись строки `Success`.
3. Установи циферблат:

   ```text
   adb -s SERIAL install -r "diasync-watchface-release-X.Y.apk"
   ```

4. Снова дождись строки `Success`.
5. Проверь наличие обоих пакетов:

   ```text
   adb -s SERIAL shell pm path ru.krotarnya.diasync2
   adb -s SERIAL shell pm path ru.krotarnya.diasync2.watchface
   ```

Обе команды должны вернуть строку, начинающуюся с `package:`. Если к компьютеру подключены только
часы, параметр `-s SERIAL` можно опустить, но явное указание устройства безопаснее.

После установки в списке приложений часов появится **Diasync**. Это диагностический экран часового
приложения, а не сам циферблат. Открой его и проверь раздел **SNAPSHOT**. После передачи данных с
телефона сверху должно появиться последнее значение вместо `NO DATA`.

## 6. Выбор циферблата и complication

1. На часах зажми текущий циферблат.
2. Открой список циферблатов через **Добавить циферблат** и найди **Diasync Watchface**. Иногда он
   находится в разделе скачанных циферблатов.
3. Выбери **Diasync Watchface**.

То же самое можно сделать через приложение **Galaxy Wearable** на телефоне: открой раздел
**Циферблаты**, найди установленный **Diasync Watchface** и примени его.

Теперь проверь источник данных:

1. Снова зажми **Diasync Watchface** и нажми **Настроить**.
2. Перейди к настройке complications и выбери большую центральную область с данными глюкозы. В
   интерфейсе она может называться **Glucose ambient value**.
3. Для этой области выбери источник **Diasync glucose**.
4. Сохрани изменения и вернись к циферблату.

Источник часто выбирается автоматически. Всё равно проверь его вручную. Если редактор показывает
дополнительный слот **Glucose**, не используй его: нужен большой центральный слот
**Glucose ambient value** с источником **Diasync glucose**.

В активном режиме циферблат должен показать время, дату, батарею, шаги, последнее значение глюкозы,
тренд и график. В ambient/AOD-режиме данные глюкозы намеренно скрыты — это штатное поведение.

## 7. Финальная проверка

1. Телефон показывает **Connected** и актуальное значение.
2. Телефон и часы остаются связанными через Galaxy Wearable.
3. Приложение **Diasync** на часах показывает полученный snapshot.
4. В большом слоте циферблата выбран **Diasync glucose**.
5. После включения экрана часов значение и график появляются на циферблате. Передача первого
   snapshot может занять до минуты; после установки разумно подождать одну-две минуты.

После успешной проверки отключи на часах **Беспроводную отладку** и **Отладку ADB**. Если включался
пункт **Отключить автоматический Wi-Fi**, верни его в прежнее состояние.

## Обновление Diasync

Для обновления скачай все три APK нового релиза с одинаковым номером версии.

1. На телефоне открой новый `diasync-app-release-X.Y.apk` и подтверди обновление.
2. Подключи часы через `adb` и повтори две команды `adb install -r` для нового `wear` и
   `watchface` APK.
3. Проверь complication. Обычно повторно выбирать его не требуется.

Если все релизы подписаны тем же ключом, настройки и локальные данные сохраняются.

## Решение проблем

### `adb` не видит часы

* Проверь, что компьютер и часы находятся в одной Wi-Fi-сети и сеть не изолирует устройства друг
  от друга. Гостевая сеть часто не подходит.
* Не путай порт сопряжения с портом подключения.
* Оставь экран **Беспроводная отладка** открытым во время `adb pair` и `adb connect`.
* Повтори `adb connect IP:PORT`, используя текущий порт с часов: после перезапуска Wi-Fi он может
  измениться.
* Отключи VPN на компьютере и телефоне на время диагностики.
* Перезапусти `adb`:

  ```text
  adb kill-server
  adb start-server
  adb connect IP:PORT
  adb devices
  ```

* Если устройство имеет статус `unauthorized` или `offline`, удали компьютер из списка сопряжённых
  устройств на часах, отзови разрешения ADB и выполни сопряжение заново.

### Подключено несколько устройств

Если `adb` пишет `more than one device/emulator`, возьми точный адрес часов из `adb devices` и
добавляй `-s SERIAL` к каждой команде.

### Конфликт подписи

Ошибки `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, `signatures do not match` или телефонное сообщение
«Приложение не установлено» обычно означают, что уже установлена сборка с другой подписью — чаще
всего старая debug-сборка.

Удаление приложения стирает его настройки и локальные данные. Сначала убедись, что у тебя есть
Backend URL и User ID / token для повторной настройки.

На телефоне удали старый **Diasync** через системные настройки, затем установи release APK заново.
На часах выполни:

```text
adb -s SERIAL uninstall ru.krotarnya.diasync2
adb -s SERIAL uninstall ru.krotarnya.diasync2.watchface
```

После этого снова установи оба APK командами из раздела 5 и повторно выбери циферблат и complication.

### `INSTALL_FAILED_VERSION_DOWNGRADE`

На устройстве уже установлена более новая версия. Используй APK последнего релиза. Если специально
нужна старая версия, сначала удали установленное приложение, учитывая потерю его настроек и данных.

### Циферблат не появился в списке

1. Проверь `pm path ru.krotarnya.diasync2.watchface` из раздела 5.
2. Перезапусти часы.
3. Снова открой список скачанных циферблатов на часах и в Galaxy Wearable.
4. Если пакет отсутствует, повтори установку и проверь, что команда завершилась строкой `Success`.

### На циферблате пусто или `NO DATA`

1. Разбуди часы: glucose-графика не показывается в ambient/AOD.
2. Проверь, что в центральном слоте выбран именно **Diasync glucose**.
3. Открой приложение **Diasync** на часах. Если snapshot там есть, проблема ограничена настройкой
   complication.
4. Если snapshot отсутствует, проверь **Connected** и наличие значения на телефоне.
5. Убедись, что телефонный и часовой APK взяты из одного релиза. Остаток debug-сборки на одном из
   устройств может установить приложение, но не позволит передавать данные из-за разной подписи.
6. Убедись, что часы подключены к телефону через Galaxy Wearable, затем подожди одну-две минуты.
